About

Halo! Saya seorang mahasiswa Teknik Informatika (Computer Science) dengan ketertarikan mendalam pada rekayasa perangkat lunak sisi server (backend development). Saya menikmati proses merancang logika bisnis yang bersih, arsitektur basis data relasional yang kokoh, dan API yang berkinerja tinggi serta aman.

Dalam pengembangan aplikasi web, fokus utama saya mencakup pembuatan endpoint RESTful API, implementasi otentikasi berbasis token (JWT & bcrypt), pengelolaan otorisasi multi-role (RBAC), serta pemodelan ORM menggunakan Sequelize dan Prisma pada basis data PostgreSQL & MySQL.

Saya terbiasa berkolaborasi dalam tim pengembang, mengikuti prinsip penulisan kode terstruktur, dan selalu antusias mempelajari teknologi baru untuk menghadirkan solusi digital yang nyata dan berdampak.
